### **General JavaScript Concepts**

- **Vanilla JavaScript**: Refers to using plain JavaScript without frameworks or libraries.
- **Hoisting**: The process by which variable and function declarations are moved to the top of their scope during the compilation phase.
- **Closures**: Functions that have access to their outer lexical environment even after the outer function has returned.
- **Promises**: Objects representing the eventual completion (or failure) of an asynchronous operation.
- **Async/Await**: Syntax for handling asynchronous code more cleanly.
- **Event Loop**: The mechanism that handles execution of multiple chunks of code, including callbacks and async operations.
- **Callback Functions**: Functions passed as arguments to other functions to be executed later.
- **Higher-Order Functions**: Functions that take other functions as arguments or return functions as results.
- **Destructuring**: Syntax for unpacking values from arrays or objects.
- **Spread Operator**: Syntax for expanding elements of an array or object.
- **Template Literals**: String literals allowing embedded expressions using backticks (``).
- **Type Coercion**: The automatic or implicit conversion of values from one type to another.

---

### **ES6+ Features**

- **Arrow Functions**: Concise syntax for writing functions.
- **Modules (import/export)**: Syntax for importing and exporting code between files.
- **Default Parameters**: Syntax to provide default values for function parameters.
- **Rest Parameters**: Syntax for gathering the rest of the arguments into an array.
- **Let and Const**: Block-scoped variables.
- **WeakMap/WeakSet**: Collections that hold weakly-referenced objects.
- **Symbol**: A unique and immutable data type used as object keys.

---

### **DOM Manipulation**

- **Document Object Model (DOM)**: A programming interface for HTML and XML documents.
- **Query Selectors**: Methods like `querySelector` and `querySelectorAll` for selecting elements.
- **Event Listeners**: Functions that respond to events like `click` or `keydown`.
- **Bubbling and Capturing**: Phases of event propagation.
- **Dynamic Content**: Adding, modifying, or removing elements in the DOM.

---

### **Web APIs**

- **Fetch API**: Interface for fetching resources asynchronously.
- **LocalStorage/SessionStorage**: APIs for storing data in the browser.
- **IndexedDB**: Low-level API for client-side storage of significant amounts of structured data.
- **Geolocation API**: Provides access to the user’s location.
- **Canvas API**: For drawing graphics on a web page.

---

### **Error Handling**

- **Try/Catch/Finally**: Syntax for handling exceptions.
- **Throw Statements**: For custom error messages.
- **Error Objects**: Instances of the `Error` class for debugging.

---

### **Performance and Optimization**

- **Debouncing/Throttling**: Techniques to control the rate of execution of a function.
- **Lazy Loading**: Deferring loading of resources until needed.
- **Tree Shaking**: Removing unused code during the build process.
- **Memoization**: Caching results of expensive function calls.
- **Server Components**: Emerging as a game-changing feature in frameworks like Next.js.
- **Edge Functions**: Running server-side code at the edge, provided by Vercel, Cloudflare Workers, and Netlify.
